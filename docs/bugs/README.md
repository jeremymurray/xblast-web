# Bug notes

One file per reported defect, named `YYYY-MM-DD-<slug>.md`. A note records the
symptom, candidate causes, evidence, paths ruled out, the experiment that
distinguishes them, and the fix plan. Update the note in place as the cause is
confirmed; do not add a second file for the same report.
